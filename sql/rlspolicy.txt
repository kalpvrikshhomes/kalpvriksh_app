2️⃣ WHAT IS WRONG / DANGEROUS 🚨
❌ BIG PROBLEM #1: SECURITY DEFINER on get_my_role()

This is the biggest red flag.

SECURITY DEFINER

Why this is dangerous

This function bypasses RLS

Any user can indirectly read profiles.role

If later you add more logic → silent privilege escalation

Supabase explicitly recommends avoiding SECURITY DEFINER for RLS helpers unless absolutely required.

👉 You do NOT need it here

✅ FIX
CREATE OR REPLACE FUNCTION get_my_role()
RETURNS role_type
LANGUAGE sql
STABLE
AS $$
  SELECT role FROM profiles WHERE id = auth.uid();
$$;


NO plpgsql
NO security definer
NO exception handling needed

If no row → returns NULL automatically.
